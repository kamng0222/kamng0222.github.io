## Transfer notes for spaceport-to-orbit feeder design (methodological; independent of any citation)

- Express-shipment SND (UPS/FedEx-type) is the closest structural analog: many origins (spokes) feed a few
  hubs within hard time windows (sort start / cut-off), aircraft routes are chosen from a candidate set on a
  time-space network, each route carries capacity, and aircraft count and balance (reusable asset cycles) are
  enforced. "Composite variables" that bundle a route with the demand it covers remove weak capacity
  coupling and give strong LP bounds; this directly fits launch-vehicle "mission" variables that bundle a
  spaceport, a launch window, a vehicle and the payload manifest it lifts to a given orbital hub.
- Hub sort capacity (packages per hour through the hub) maps to orbital-hub berthing/transfer capacity per
  phasing window; banked schedules (waves of arrivals then departures) map to orbital phasing bands.
- Fleet assignment on a time-space network with ground arcs and turnaround minima gives the reusable-booster
  rotation model (pad turnaround, refurbishment as "maintenance checks"); flight-string / rotation-tour
  formulations handle cumulative-cycle limits exactly as they handle maintenance-interval limits.
- Integrated schedule design + fleet assignment (choose which legs to fly, then which vehicle type) is the
  natural model for choosing which launch windows to open and which vehicle class to assign, with
  spill/recapture logic transferring to payload deferral to a later window.
- Time-definite delivery network design (service-level cut-offs by origin-destination pair) supplies the
  lead-time-constrained routing logic for payloads with orbital-insertion deadlines.
- Hub-and-spoke vs point-to-point economics (frequency, consolidation, scale economies at hubs vs direct
  service) frames the strategic question of how many orbital hubs/depots to operate vs direct-to-target
  launches.
